# 🛡️ CyberShield

CyberShield is an AI-powered Cyber Security & Digital Fraud Prevention Platform developed to help users detect, prevent, and respond to cyber threats and digital fraud.

---

## 🚀 Features

- 🔐 Secure User Authentication
- 🤖 AI Cyber Coach
- 📊 Live Threat Monitoring
- 🚨 Panic Mode for Emergency Situations
- 📍 Location Sharing
- 🔔 Real-time Notifications
- 📂 Digital Evidence Collection
- 📈 Risk Analysis Dashboard

---

## 🛠️ Tech Stack

### Frontend
- FlutterFlow

### Backend
- Python
- FastAPI
- Swagger / OpenAPI
